    Keyboard shortcuts

    N
    Add an item. Not offered on a shared trip, which you cannot edit.
    Ctrl + Z
    Undo the last change, 50 steps deep (⌘ in place of Ctrl on a Mac).
    Ctrl + Y
    Redo. Ctrl + Shift + Z does the same.
    Esc
    Close the topmost layer, one press per layer: an open dialog first, then the assistant, then the search or trip menu.
    Enter / Space
    On a focused night-coverage cell: jump to the item covering that night.
    Tab
    Move between controls. While a dialog is open, focus stays inside it.
    ?
    Open this list. Typing into a text field never triggers it.

    Views have addresses too: ending the URL with #timeline, #days or #map opens straight into that view, and the view you switch to is kept there so a refresh comes back to it.
