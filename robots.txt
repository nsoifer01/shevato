# robots.txt for shevato.com
#
# Default policy: allow all well-behaved crawlers.
# Search engines (Google, Bing, etc.) and SEO research tools (Ahrefs, Semrush)
# are intentionally permitted so the site is discoverable and so external
# backlink/visibility analysis can find shevato.com.
#
# THE RULE THAT MATTERS HERE: never Disallow a path the pages themselves
# load. Google's rendering service does not fetch robots-blocked
# subresources, so a Disallow on something a page fetches deletes that
# content from the DOM Google indexes - it does not merely hide a file.
# /partials/, /sync-system/ and /firebase-config.js were all disallowed here
# until 2026-09-04, and assets/js/main.js fetches /partials/header.html and
# /partials/footer.html on every page: the site's entire header and footer
# navigation was therefore absent from every page Google rendered, leaving
# six of the eight app pages with zero internal outbound links and /privacy
# with zero inbound ones. tests/static/robots-references.test.mjs now fails
# if any path referenced by a page is matched by a Disallow rule below.
